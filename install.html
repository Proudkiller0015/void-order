📱 On a phone (or if dragging doesn't work)

  2. Make a new bookmark: on a computer press Ctrl + D on this page; on a phone tap ☆ (or ⋮ › ☆).
  3. Edit it (on a phone: ⋮ › Bookmarks, then the bookmark's ⋮ › Edit): name it void, and replace its address (URL) with what you copied. Save.
    ⚠ The address must start with javascript:. Some browsers (Chrome) drop that word when you paste; if it's missing, type javascript: back at the very start. Without it the browser just searches for the code.
  4. Open Bondage Club and log in, then open the bookmark:
    • Computer: click it in your bookmarks.
    • Phone: type void in the address bar and tap the bookmark in the suggestions, not a search (phones only run bookmarks this way).
  5. Type /void in a chat room (or click the ⸸ tab on the left) to open the Order.

Open it each time you open the game. It always loads the newest version, so there's never anything to update. Opening it twice does nothing extra.
